## 🎯 Цель исследования

Выяснить, какой способ поиска позволяет компьютеру найти загаданное число за меньшее количество попыток.

## 🧠 Алгоритмы поиска

В исследовании сравниваются три алгоритма.

- **Последовательный поиск** — проверяет числа по порядку, одно за другим.
- **Случайный поиск** — выбирает случайные числа, которые ещё не проверялись.
- **Бинарный поиск** — проверяет середину диапазона и каждый раз отбрасывает половину вариантов, в которой загаданного числа быть не может.

## 🧪 Эксперимент

Для сравнения алгоритмов была написана программа на Python.

Условия эксперимента:

- Диапазоны чисел: **1–100** и **1–1000**.
- Количество испытаний: **1000 для каждого диапазона**.
- Во время одного испытания все три алгоритма ищут одно и то же загаданное число.
- Основной показатель сравнения — среднее количество попыток.

## 📊 Результаты

| Диапазон | Последовательный поиск | Случайный поиск | Бинарный поиск |
|:--------:|-----------------------:|----------------:|---------------:|
| 1–100 | 50,770 | 51,601 | **5,861** |
| 1–1000 | 512,559 | 499,323 | **8,972** |

Средние значения получены в ходе компьютерного эксперимента. При повторном запуске они могут немного измениться.

### Что показывают результаты?

- В диапазоне 1–100 бинарному поиску понадобилось в среднем около 6 попыток.
- В диапазоне 1–1000 — около 9 попыток.
- Последовательному и случайному поиску в большом диапазоне потребовалось в среднем около 500 попыток.

**В проведённом эксперименте бинарный поиск потребовал значительно меньше попыток, чем два других алгоритма.**

## 🎮 Попробуй сам

В проекте есть игра, в которой можно загадать число от 1 до 100 и посмотреть, как компьютер выполняет поиск с помощью бинарного алгоритма.

Чтобы запустить игру, перейдите в корневую папку проекта и выполните:

```bash
python game/guess_game.py
```

Для запуска эксперимента:

```bash
python research/experiment.py
```

Для построения графиков:

```bash
python research/plot_results.py
```

Для построения графиков требуется библиотека Matplotlib. При необходимости её можно установить командой:

```bash
python -m pip install matplotlib
```

## 💡 Вывод

В ходе исследования выяснилось, что одну задачу можно решать разными алгоритмами, но количество необходимых действий может сильно отличаться.

**Бинарный поиск оказался наиболее эффективным по количеству попыток**, потому что на каждом шаге сокращает диапазон поиска примерно в два раза.
