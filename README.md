Какой способ поиска позволяет компьютеру найти загаданное число за меньшее количество попыток?

Исследовательский проект для школьной конференции «За наукой будущее».

Цель

Сравнить разные способы поиска загаданного числа и определить, какой из них позволяет найти число за меньшее количество попыток.

Исследуемые способы
последовательный поиск;
случайный поиск;
бинарный поиск.

Эксперимент проводился 1000 раз для диапазонов от 1 до 100 и от 1 до 1000.

Для каждого способа подсчитывалось количество попыток.

Результат

Бинарный поиск оказался значительно эффективнее последовательного и случайного.

В среднем:

Диапазон	Последовательный	Случайный	Бинарный
1–100	≈ 50	≈ 50	≈ 6
1–1000	≈ 500	≈ 500	≈ 9

Точные результаты находятся в results/results.csv.

Графики находятся в папке results.

Запуск

Установить matplotlib:

pip install matplotlib

Провести эксперимент:

python research/experiment.py

Построить графики:

python research/plot_results.py

Запустить игру:

python game/guess_game.py
Вывод

Бинарный поиск позволяет найти загаданное число за значительно меньшее количество попыток.
